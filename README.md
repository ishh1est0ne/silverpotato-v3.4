# silverfish (v3.9-pre-release)

Клиент-серверное мобильное приложение для фото-квестов с дедлайнами, лентой отчетов, встроенным мессенджером реального времени и панелью администрирования.

Стек:
- Клиент: Next.js 16 (React 19), Tailwind CSS, Capacitor 8 (Android)
- Сервер: Node.js, Express, Socket.io
- База данных: PostgreSQL 16
- Сеть: Proxmox VE (LXC контейнер), Tailscale VPN

---

## Архитектура системы

```
[ Android APK (Capacitor) / Браузер ]
                 │
                 ├── HTTP REST (Авторизация, Задачи, Посты) ──> [ Express API :4000 ]
                 └── WebSocket (Socket.io - Чат, Статусы)    ──> [ Socket.io :4000 ]
                                                                        │
                                                                   pg (Pool)
                                                                        │
                                                              [ PostgreSQL :5432 ]
```

Сервер разворачивается в локальной сети или через Tailscale (хост `100.106.175.106:4000`).
Корень сервера (`/`) отдает статическую посадочную веб-страницу со статусом API и ссылкой на APK.

## Реализованный функционал (v3.9-pre-release)

1. **Интерфейс**:
   - Полноценная AMOLED темная тема (глубокий черный фон `#09090b` / `#141418`, контрастные карточки, отсутствие белых модальных окон).
   - Плавные CSS-анимации появления экранов, модальных окон и списков.
   - Постоянная сессия: пользователь остается авторизованным после перезапуска приложения.

2. **Фото-квесты и дедлайны**:
   - Банк из 35 фото-челленджей.
   - Жесткий дедлайн: 10 минут на выполнение после выпадения квеста.
   - Живой таймер обратного отсчета на карточках и в модальном окне сдачи.
   - Автоматический штраф (-50 очков) при истечении таймера без сданного отчета.
   - Возможность взять задание самостоятельно (лимит: 2 раза в сутки).
   - Поддержка прикрепления фото как напрямую с камеры, так и выбором из галереи устройства.

3. **Мессенджер реального времени**:
   - Двусторонняя доставка сообщений через WebSocket (Socket.io).
   - Статусы сообщений: отправляется, доставлено, прочитано.
   - Отметка о прочтении при открытии диалога.
   - Список пользователей онлайн с отображением времени последней активности.
   - Скрытие email-адресов пользователей в поиске для безопасности.

4. **Администрирование**:
   - Предустановленный аккаунт администратора (`admin` / `admin`).
   - Верхняя панель быстрой навигации по экранам (отображается только для роли `admin`).
   - Кнопка принудительного завершения дедлайна квеста в карточке задания.

5. **Безопасность и профиль**:
   - Хеширование паролей (bcryptjs).
   - Авторизация через JWT Bearer токены.
   - Рабочий процесс сброса пароля по токену.
   - Информационный блок о подключении к серверу и базе вынесен из профиля в раздел настроек.
   - Реальная статистика пользователя (роль, баланс, выполненные квесты, оставшиеся попытки на день).

## Развертывание сервера

### Требования
- Ubuntu 22.04 / 24.04 (LXC или VM в Proxmox)
- Node.js 20+
- PostgreSQL 14+

### 1. Настройка базы данных
```bash
sudo -u postgres psql
```
```sql
CREATE USER photouser WITH PASSWORD 'supersecret123';
CREATE DATABASE photodb OWNER photouser;
GRANT ALL PRIVILEGES ON DATABASE photodb TO photouser;
\q
```

Импорт структуры:
```bash
psql -U photouser -d photodb -h 127.0.0.1 -f server/schema.sql
```

### 2. Конфигурация окружения
Создайте файл `server/.env`:
```env
PORT=4000
DATABASE_URL=postgresql://photouser:supersecret123@127.0.0.1:5432/photodb
JWT_SECRET=super_safe_production_jwt_key_2026
FRONTEND_URL=*
```

### 3. Запуск сервера
```bash
cd server
npm install
node index.js
```

Для постоянной работы в фоне используйте PM2:
```bash
npm install -g pm2
pm2 start index.js --name silverfish-server
pm2 startup
pm2 save
```

Сервер слушает порт 4000. Веб-интерфейс доступен по адресу `http://<IP_СЕРВЕРА>:4000/`.

## Сборка клиентского приложения

### 1. Настройка подключения
Создайте `.env.local` в корне проекта:
```env
NEXT_PUBLIC_API_URL=http://100.106.175.106:4000
```

### 2. Сборка веб-части
```bash
npm install
npm run build
```
Статический бандл формируется в директории `out/`.

### 3. Синхронизация с Android и сборка APK
```bash
npx cap sync
cd android
./gradlew assembleDebug
```

Готовый файл APK:
`android/app/build/outputs/apk/debug/app-debug.apk`

## API Эндпоинты

### Аутентификация
- `POST /api/auth/register` — регистрация (`name`, `email`, `password`)
- `POST /api/auth/login` — вход (`email` или `login`, `password`)
- `GET /api/auth/me` — данные текущей сессии
- `POST /api/auth/forgot-password` — запрос сброса пароля
- `POST /api/auth/reset-password` — установка нового пароля по токену

### Квесты и задания
- `GET /api/tasks` — список активных и выполненных заданий
- `POST /api/tasks` — создание пользовательского задания
- `POST /api/tasks/drop-daily` — генерация случайного квеста дня (дедлайн 10 минут)
- `POST /api/tasks/take-self` — самостоятельное взятие квеста (до 2 раз в день)
- `POST /api/tasks/:id/complete` — сдача отчета с фотографией
- `POST /api/admin/tasks/:id/expire-now` — админское досрочное завершение задания

### Посты и активность
- `GET /api/posts` — лента завершенных фото-отчетов
- `POST /api/posts/:id/like` — переключение лайка
- `GET /api/posts/:id/comments` — список комментариев
- `POST /api/posts/:id/comments` — добавление комментария

### Мессенджер
- `GET /api/conversations` — список диалогов пользователя
- `GET /api/conversations/:id/messages` — история сообщений диалога
- `POST /api/conversations/:id/messages` — отправка сообщения
- `POST /api/conversations/:id/read` — отметка сообщений прочитанными
- `GET /api/users` — список пользователей (без email, с отметкой онлайн/last_seen)

### Сервис
- `GET /api/health` — проверка состояния сервера и подключения к PostgreSQL
- `GET /` — веб-сайт проекта
