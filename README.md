# 📸 Фото-Квесты (BeReal-style Mobile App)

> Полнофункциональное мобильное приложение на **React / Next.js**, упаковываемое в **Android APK (Capacitor)**, с поддержкой собственного **Node.js + PostgreSQL** бэкенда на сервере **Proxmox**, мгновенным чатом на **Socket.io** между двумя смартфонами, ежедневными случайными фото-заданиями с таймерами и защищенной авторизацией (bcrypt + JWT + сброс пароля).

---

## 🌟 Основные возможности проекта

1. **Чистая русская локализация**:
   - Все экраны переведены на русский язык без смешивания терминов: экран входа («Вход»), регистрации («Регистрация»), восстановления пароля («Сброс пароля» и «Новый пароль»), лента заданий, чаты и профиль.
   - Одинаковый шрифт и размер заголовков на экранах входа и регистрации (`font-mono text-3xl font-medium`).

2. **20 случайных фото-заданий дня (в стиле BeReal)**:
   - Встроенный банк из **20 уникальных креативных фото-челленджей** («Сфотографируй воду», «Сфотографируй небо над собой», «Сфотографируй свой горячий напиток», «Сфоткай отражение в зеркале» и др.).
   - Автоматическая публикация в случайное время или ручной триггер для демонстрации кнопкой **«⚡ Случайный дроп дня (BeReal)»**.
   - **Живые таймеры обратного отсчета (секундомеры)**: тикают в реальном времени на карточках заданий и в модальных окнах, подсвечивая оставшееся время и предупреждая о дедлайне.
   - Сдача фото-отчетов прямо с камеры смартфона или из галереи с сохранением выполненных постов и комментариями.

3. **📸 Лента постов (Posts Feed)**:
   - Отдельный удобный экран со всеми завершенными фото-квестами пользователей.
   - Полноразмерные фото-отчеты в высоком разрешении с указанием автора, задания и времени выполнения.
   - Интерактивные счетчики лайков с тактильным откликом.
   - Полноценная ветка комментариев под каждым постом с поддержкой моментальной отправки без перезагрузки экрана и четко видимым полем ввода текста.

4. **👥 Поддержка одновременной работы нескольких пользователей (Multi-User)**:
   - Полная изоляция сессий: при тестировании с одного компьютера в разных вкладках браузера или с двух разных смартфонов через APK действия каждого пользователя не пересекаются и не затирают чужие настройки.
   - Каждый участник оставляет комментарии, ставит отметки и отправляет сообщения от своего настоящего имени и ID.
   - Интеллектуальное слияние локального кэша и серверной базы PostgreSQL исключает исчезновение постов при публикации комментариев.

5. **💬 Мгновенный чат между устройствами (Android / ПК)**:
   - Полноценная работа с двумя разными аккаунтами на двух смартфонах или в браузере.
   - Связь в реальном времени через **WebSocket (Socket.io)**: сообщения мгновенно отображаются у собеседника без перезагрузки экрана.
   - Корректное разделение входящих и исходящих сообщений с индикацией имени и времени.
   - Вибрация (Haptic feedback) и локальные пуш-уведомления при поступлении сообщений на устройстве.
   - Экран выбора собеседника из базы зарегистрированных пользователей онлайн.

6. **🔒 Безопасность и сброс пароля**:
   - Надежное хеширование паролей с солью через **bcryptjs** (10 раундов).
   - Авторизация по **JWT-токенам** с валидацией сессии в Middleware.
   - Рабочий механизм восстановления забытого пароля: генерация токена, отправка ссылки на почту через SMTP или мгновенный переход по демо-токену для презентации комиссии.
   - Защита от ошибок формата `Unexpected token '<', <!DOCTYPE`: клиентское приложение безопасно валидирует MIME-типы и не падает, даже если удаленный сервер временно вернул HTML 404.

## ⚡ 3 Режима работы (Гибкость архитектуры)

Приложение автоматически адаптируется под доступную инфраструктуру:

1. **Режим 1: Автономный (Local Mock DB)** — работает «из коробки» без бэкенда и интернета в браузере или APK. Все данные сохраняются в локальное хранилище.
2. **Режим 2: Собственный сервер Proxmox (Рекомендуется для защиты)** — подключение к вашему серверу Node.js + PostgreSQL через переменную `NEXT_PUBLIC_API_URL=http://<IP-вашего-сервера>:4000`.
3. **Режим 3: Облачный Supabase** — подключается при наличии ключей в `.env.local` (`NEXT_PUBLIC_SUPABASE_URL`).

## 🖥️ Развертывание сервера на Proxmox VE

Для диплома и защиты идеальным вариантом является развертывание в отдельном LXC-контейнере или виртуальной машине (Ubuntu 22.04 / 24.04 LTS).

### Шаг 1. Создание контейнера в Proxmox
1. В веб-интерфейсе Proxmox нажмите **Create CT** (LXC).
2. Выберите шаблон **Ubuntu 24.04** или **Debian 12**.
3. Выделите ресурсы: 1-2 vCPU, 1024-2048 МБ RAM, 10 ГБ диска.
4. Задайте статический IP или запомните выданный DHCP IP (например, `192.168.1.150`).

### Шаг 2. Установка Node.js и PostgreSQL на сервере
Войдите в консоль контейнера:
```bash
# Обновление пакетов
apt update && apt upgrade -y

# Установка Node.js 20+ и npm
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs postgresql postgresql-contrib git

# Проверка версий
node -v
psql --version
```

### Шаг 3. Настройка базы данных PostgreSQL
```bash
# Переключение на пользователя postgres
su - postgres

# Создание базы данных и пользователя
psql -c "CREATE USER photouser WITH PASSWORD 'supersecret123';"
psql -c "CREATE DATABASE photodb OWNER photouser;"
psql -c "GRANT ALL PRIVILEGES ON DATABASE photodb TO photouser;"
exit
```

Импортируйте готовую схему из файла `server/schema.sql`:
```bash
psql -U photouser -d photodb -h 127.0.0.1 -W < /путь_к_проекту/server/schema.sql
```

### Шаг 4. Настройка и запуск бэкенда
Перейдите в папку `server/`:
```bash
cd server
npm install

# Создайте файл .env на основе .env.example
cat <<EOF > .env
PORT=4000
DATABASE_URL=postgresql://photouser:supersecret123@127.0.0.1:5432/photodb
JWT_SECRET=diplom_secret_jwt_key_2026_super_safe
FRONTEND_URL=http://192.168.1.150:3000

# Опционально: SMTP для отправки писем при сбросе пароля
# SMTP_HOST=smtp.mail.ru
# SMTP_PORT=465
# SMTP_USER=your_mail@mail.ru
# SMTP_PASS=your_app_password
EOF
```

Для фонового непрерывного запуска установите менеджер процессов **PM2**:
```bash
npm install -g pm2
pm2 start index.js --name "photo-backend"
pm2 startup
pm2 save
```
Бэкенд запущен и слушает порт `4000`.

## 📱 Сборка Android APK через Capacitor

Чтобы превратить проект в готовый `.apk` для установки на смартфон:

### 1. Настройка адреса API
В корне проекта создайте или отредактируйте `.env.local`:
```env
# Укажите IP-адрес вашего контейнера в Proxmox
NEXT_PUBLIC_API_URL=http://192.168.1.150:4000
```

### 2. Экспорт веб-сборки и синхронизация Capacitor
```bash
# Сборка статики Next.js в папку out/
npm run build

# Синхронизация файлов с Android проектом
npx cap sync
```

### 3. Разрешение HTTP-трафика для локальной сети Proxmox
При подключении по обычному `http://` (без HTTPS-сертификата) на Android необходимо разрешить незашифрованный трафик. В файле `android/app/src/main/AndroidManifest.xml` внутри тега `<application>` добавьте флаг:
```xml
<application
    android:usesCleartextTraffic="true"
    ... >
```

### 4. Сборка APK в Android Studio или через Gradle
```bash
# Открыть проект в Android Studio
npx cap open android

# Или собрать APK напрямую через командную строку
cd android
./gradlew assembleDebug
```
Готовый установочный файл будет в: `android/app/build/outputs/apk/debug/app-debug.apk`. Установите его на оба смартфона!

## 👥 Сценарий тестирования на защите (Два устройства)

Для демонстрации комиссии:

1. **Устройство 1 (Смартфон А)**:
   - Откройте приложение, перейдите на экран **Регистрация**.
   - Создайте аккаунт: Имя: `Алексей`, Email: `alex@test.ru`, Пароль: `123456`.
   - Нажмите **ВОЙТИ**.

2. **Устройство 2 (Смартфон Б или Ноутбук)**:
   - Зарегистрируйте аккаунт: Имя: `Мария`, Email: `maria@test.ru`, Пароль: `123456`.
   - Нажмите **ВОЙТИ**.

3. **Проверка чата в реальном времени**:
   - На Устройстве 1 перейдите на вкладку **Сообщения**, нажмите иконку **+** (Начать чат).
   - В списке пользователей в сети появится `Мария`. Нажмите **«Написать →»**.
   - Отправьте сообщение: *«Привет! Ты уже видела сегодняшнее фото-задание?»*.
   - **Результат**: На Устройстве 2 сообщение появится моментально через Socket.io со срабатыванием вибрации! Мария отвечает — ответ мгновенно виден у Алексея.

4. **Проверка фото-заданий и секундомеров**:
   - Нажмите желтую кнопку **«⚡ Случайный дроп дня (BeReal)»**.
   - Появится новое задание дня с живым тикающим таймером обратного отсчета (например, *«Сфотографируй воду (стакан, река, лужа или капли)»*).
   - Нажмите на карточку задания, прикрепите фото с камеры смартфона и нажмите **«Подтвердить выполнение»**.
   - Карточка получит зеленый статус **«Выполнено»** и покажет прикрепленный фото-отчет!

5. **Проверка восстановления пароля**:
   - На экране входа нажмите **«Забыли пароль?»**.
   - Введите почту и нажмите **«ОТПРАВИТЬ ССЫЛКУ»**.
   - В тестовом режиме отобразится кнопка мгновенного перехода **«Ввести новый пароль»**, позволяющая сменить пароль и войти с новыми данными.

## 🎓 Готовность к защите дипломного проекта

* **Frontend**: Современный стек React 19 / Next.js, чистый адаптивный UI с поддержкой рамки мобильного устройства, жестов и темной панели.
* **Backend**: Собственный полнофункциональный сервер на Express и Socket.io, независимый от сторонних платных сервисов.
* **База данных**: Реляционная PostgreSQL с оптимизированными индексами и связями.
* **Безопасность**: Стандарты OWASP — bcrypt хеширование, JWT токены в заголовках `Authorization`, параметризованные SQL-запросы без SQL-инъекций.
